# 05 - 画质选项与性能影响

> 逐项说明 re3 的画质/图形选项，标注对 VideoCore IV（带宽/填充率受限）的性能影响，指导"关增强特效换帧率"的取舍。

## 1. 后处理类（全屏，带宽/填充率大户）

| 选项 | 作用 | 性能影响 | 建议 |
|---|---|---|---|
| **Colour Filter** | 全屏颜色后处理 | Normal/Mobile **每帧全屏 backbuffer 拷贝**；Simple/None 不拷贝 | **设 Simple/None**（画面变亮、少了冷色调氛围） |
| **Motion Blur (Trails)** | PS2 拖影 | 保留上一帧到 frontbuffer 再混合 = 全屏拷贝 | **关** |
| **MultiSampling (MSAA)** | 多重采样抗锯齿 | 每像素多次采样，**填充率杀手** | **关**（保持 0） |

`re3.ini [Graphics]`：`ColourFilter`（0=None,1=Simple,2=Normal,3=Mobile）、`MotionBlur`、`MultiSampling`。

### Colour Filter 各值

| 值 | 名称 | backbuffer 拷贝 | 画面 |
|---|---|---|---|
| 0 | None | ❌ | 原始，最亮 |
| 1 | Simple | ❌ | 简单叠加 |
| 2 | Normal（默认） | ✅ 每帧 | 冷色调+对比度（自由城氛围） |
| 3 | Mobile | ✅ | 手机版滤镜 |

> 注：`NeedBackBuffer()` 中 `POSTFX_NORMAL` 若 MotionBlur 开启则改用 frontbuffer（仍全屏拷贝）。Simple/None 才真正免拷贝。

## 2. PS2/Xbox 增强类（原版 PC 无）

| 选项 | 作用 | 性能影响 |
|---|---|---|
| PS2 Alpha Test | 还原 PS2 alpha 测试 | 轻微 |
| Trails | 同 Motion Blur | 全屏拷贝 |
| 屏幕雨滴 (SCREEN_DROPLETS) | Xbox 全屏雨滴（config.h，非菜单） | **下雨时全屏拷贝+全屏后处理，已关（RPI_LEAN_FX）** |

## 3. Neo 管线类（SkyGFX 风格增强，额外 shader/带宽）

`re3.ini [Graphics]`：`VehiclePipeline`、`NeoRimLight`、`NeoLightMaps`、`NeoRoadGloss`。

| 选项 | 作用 | 性能影响 | 建议 |
|---|---|---|---|
| Vehicle Pipeline (Neo) | PS2 风格车漆世界反射 | 额外渲染 pass | 可关 |
| Neo Rim Light | 边缘高光（Xbox） | 额外片元计算 | 可关 |
| Neo Light Maps | Xbox 世界光照贴图（需 Xbox 地图） | 额外采样 | 可关 |
| **Neo Road Gloss** | 湿路面反射光泽 | **下雨时半透明叠加，吃填充率** | **下雨场景建议关** |

## 4. 画面距离/密度类

| 选项 | 作用 | 性能影响 |
|---|---|---|
| **Draw Distance** | 可见范围（ini 默认 1.2） | **拉近省几何+overdraw+CMA** |
| Ped Density | 行人数量 | CPU(AI)+几何，GPU 瓶颈下收益小 |
| Car Density | 车辆数量 | 同上 |

## 5. 不影响性能

Aspect Ratio、Brightness、Subtitles、Cutscene Borders、Free Cam、Island Loading（影响内存/加载非帧率）。

## 6. 测量类（测性能时的设置）

| 选项 | 测性能时 | 说明 |
|---|---|---|
| VSync | 关(0) | 否则锁帧+等待，掩盖真实性能 |
| Frame Limiter | 关(0) | 否则锁 30fps |

## 7. "关增强换帧率"清单（VC4 推荐）

| 选项 | 动作 | 收益 | 已验证 |
|---|---|---|---|
| Colour Filter → Simple/None | 免全屏拷贝 | 常驻带宽 | ✅ 帧率↑、画面变亮 |
| Motion Blur → 关 | 免 frontbuffer 拷贝 | 常驻带宽 | ✅ |
| MultiSampling → 关 | 免多采样 | 填充率 | ✅（已 0） |
| 屏幕雨滴 → 关 | 免下雨全屏后处理 | 下雨 12→20+fps | ✅ |
| Neo Road Gloss → 关 | 免湿路面叠加 | 下雨填充率 | ⬜ 待测 |
| Neo Rim/Vehicle → 关 | 免额外 pass | 片元 | ⬜ 待测 |
| Draw Distance → 调小 | 减几何/overdraw/CMA | 全局 | ⬜ 待测 |

> 取舍原则：这些多是原版 PC/PS2 GTA III 没有的增强特效，关掉更接近原版观感，且直接换取带宽/填充率。
